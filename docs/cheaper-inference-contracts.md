# Контракты Cheaper Inference в Koteyye Media Studio

Сверка от 26 ноября 2026 года охватывает восемь режимов генерации и сервисные запросы, которые выполняет студия. Источник полей и ограничений — опубликованная схема API и руководство сервиса. [OpenAPI](https://api.cheaperinference.com/openapi.json) · [Документация](https://www.cheaperinference.com/docs)

| Операция | Что учитывает студия |
| --- | --- |
| Проверка ключа · `GET /v1/models?type=decision` | Проверяет Bearer и наличие массива моделей. Пустой список допустим. 401 означает отклонённый ключ. Ошибки сети и ограничения доступа показываются отдельно. Введённый ключ можно проверить до сохранения. |
| Публичный каталог · `GET /public/models` | Запрос без заголовка авторизации. Из массива `models` читаются `model_type`, `provider_name`, `features`, плоские цены и таблицы `pricing_scopes`. |
| Каталог с ключом · `GET /v1/models?type=…` | Для изображений, видео и аудио запрашиваются типы `image`, `video` и `speech`. Массив `data` содержит `type`, `provider`, `capabilities`, `supported_endpoints` и `pricing`. Селектор использует операции, объявленные в ответе с ключом. При противоречии между `capabilities.image_edit` и списком эндпоинтов редактирование доступно только при подтверждении обоих. Цены берутся из `media_unit_price`, `resolution_prices` и `scopes` внутри `pricing`. После смены ключа студия перечитывает каталоги и баланс. |
| Изображение · `POST /v1/images/generations` | В запрос уходят модель, промпт и выбранные параметры. Каждый элемент `data` может содержать изображение в `b64_json` или ссылку `url`. |
| Редактирование · `POST /v1/images/edits` | Локальные файлы передаются в multipart как поля `image` с исходными байтами PNG, JPEG или WebP. Допустимо от одного до десяти исходников. Отдельное поле `mask` принимает PNG. При наличии HTTP(S)-ссылки студия использует JSON с `input_references` для всего набора, включая локальные data URL. При 5xx автоматической повторной отправки нет. Если шлюз сообщил идентификатор, он виден в ошибке и в истории. |
| Видео · `POST /v1/videos/generations` | Длительность положительная. Первый кадр передаётся в `image_url`, референсы — в `input_references`. У вариантов `t2v`, `i2v` и `r2v` разные входы. Студия распознаёт URL и MP4 в `b64_video`. Статус расчёта стоимости обрабатывается отдельно от готовности файла. |
| Речь, музыка и звуковые эффекты · `POST /v1/audio/speech` | Три режима используют `model` и `input`. Для синтеза речи доступны опциональные параметры голоса, скорости и формата. Результат приходит бинарным телом. Для моделей с посекундной тарификацией до генерации показывается ставка. |
| Получение сохранённого результата · `GET /v1/generations/{request_id}` | Идентификатор читается из тела или заголовков, включая `x-request-id` для white-label ключей. После сбоя получения оплаченного ответа студия использует сохранённую квитанцию и заново запрашивает ссылки. Срок ссылки — час, срок хранения у CI — семь дней. При ZDR хранение отключено. |
| Баланс · `GET /v1/account/balance` | По запросу пользователя студия показывает доступную сумму `available_usd`. Для неё нужен scope `account:read`. Локальный расход складывается из известных сумм списания. Для ключей без данных о списании итог в истории может оставаться неизвестным. |

Для больших JSON-запросов генерации изображений и видео студия использует gzip. Проверяются оба предела шлюза — 4,5 МБ на проводе и 20 МБ после распаковки. При редактировании студия проверяет размер целого multipart или JSON с учётом полей запроса. Если тело превышает лимит, форма предлагает уменьшить файл или указать HTTP(S)-ссылку. [Лимиты запросов](https://www.cheaperinference.com/docs#compressed-request-bodies)

## Проверка

Нативные команды студии с сохранённым ключом прошли проверку на живом API. На момент проверки сервис вернул 48 моделей изображений, 37 видео и 24 аудио. В отдельном окне WebView2 на Windows кнопка «Проверить соединение» приняла сохранённый ключ, мастер открыл выбор папки и завершился переходом в студию. Эти числа зависят от ключа и состояния каталога. Ручной тест `cargo test -p koteyye-media-studio --test live_catalog -- --ignored --nocapture` выводит только число моделей по категориям.

Для платных операций используются локальные HTTP-тесты. Они проверяют тело и заголовки запросов, форматы ответов, запись файлов, учёт стоимости и повторное получение по идентификатору. Реальный выход конкретного поставщика можно проверить при пользовательской генерации. [Медиа](https://www.cheaperinference.com/docs#images-and-vision) · [Аудио](https://www.cheaperinference.com/docs#voice-sessions) · [Восстановление](https://www.cheaperinference.com/docs#fetch-results-again)

У видео общий флаг `image-input` указывает на возможность использовать изображение. Для списка референсов студия учитывает специализированные идентификаторы, варианты цен и опубликованные возможности конкретных моделей.
